Task 2: Data Cleaning and Exploratory Data Analysis (EDA)

Objective:
To perform data cleaning and exploratory data analysis (EDA) on the Titanic dataset, explore relationships between variables, and identify patterns and trends in the data.

Dataset:
Titanic Dataset-The dataset contains information about passengers, including:
Age
Gender
Passenger Class
Fare
Survival Status
Embarked Port

Tools & Technologies:
Python
Pandas
Matplotlib
Seaborn
Google Colab
Data Cleaning
The following data cleaning steps were performed:

Checked for missing values.
Filled missing Age values using the median.
Filled missing Embarked values using the mode.
Filled missing Fare values using the median.
Removed duplicate records.

Exploratory Data Analysis:
The following analysis and visualizations were performed:

Survival distribution
Gender distribution
Gender vs. Survival
Passenger Class vs. Survival
Age distribution
Age vs. Survival
Correlation heatmap
Survival rate by gender
Survival rate by passenger class

Key Findings:
Female passengers had a higher survival rate than male passengers.
Passenger class had a relationship with survival.
Higher-class passengers generally had better survival rates.
Passengers belonged to a wide range of age groups.
Data visualization helped identify important patterns and relationships in the dataset.

Conclusion:
The Titanic dataset was successfully cleaned and analyzed using exploratory data analysis techniques. The analysis helped identify relationships between gender, passenger class, age, and survival. Visualizations made the patterns and trends in the data easier to understand.
